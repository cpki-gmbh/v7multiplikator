# build_c_targets.txt -- C/C++ build-target manifest for build.bat's freshness gate
#
# Consumed by src/check_stale.py. One record per line, '|'-delimited:
#
#     <source>|<output>[;<output>...][|<extra-input>[;<extra-input>...]]
#
#   field 1  source file, relative to the project root
#   field 2  output file(s), relative to the project root. ';' separated.
#   field 3  OPTIONAL target-specific extra inputs, ';' separated.
#            A trailing-slash path means "every file under this tree, recursively"
#            (used only for the NASM target, whose real dependency is 114 .inc files).
#
# Blank lines and lines starting with '#' are ignored.
#
# Per-target inputs are the source, field-3 extras, Zydis.lib, every *.h in the
# source's own directory, every *.h directly in src\, and every *.h in the project
# root. That is a deliberate SUPERSET of the real dependency set: it can only
# over-trigger a rebuild, never under-trigger one.
#
# src/v7_threading.def stands in for the DLL import surface on the two targets that
# link bin\v7_threading.lib. The .lib itself is deliberately NOT an input: step 1
# regenerates it on every single run, so comparing its mtime would make the gate
# report STALE after every ASM-only edit and destroy the entire point of the gate.
